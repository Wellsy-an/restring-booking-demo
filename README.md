# RestRing — Course Demonstration

RestRing is an independent BNBU course-project concept for midday rest pods. This is **not an official university service or a real reservation system**, and does not imply that the proposed facility has been built.

RestRing 是独立课程项目的午休舱概念演示，**非学校官方服务，不提供真实预约**，亦不表示提案设施已经建成。

## Open the demonstration / 打开演示

Visit [the GitHub Pages website](https://wellsy-an.github.io/restring-booking-demo/), or download `index.html` and open it locally in a modern browser. The page is self-contained and requires no external libraries, accounts, passwords, payment, or backend.

直接打开 [GitHub Pages 网页](https://wellsy-an.github.io/restring-booking-demo/)，或下载 `index.html` 后在现代浏览器中打开。页面为独立单文件，无外部库，无需账号密码、付款或后端。

## Demo data and privacy / 演示数据与隐私

- All student identities, occupancy, reservations, credit scores, student-card checks and door events are simulated.
- Reservations and settings use the current browser's localStorage. **Data is local to each browser and device and is not shared or synchronized between visitors.** Downloaded copies and the hosted website also have separate browser-storage contexts.
- No real university identity integration, camera access, facial recognition, or biometric collection is implemented.
- Demo tools can change fictional students and simulate usage. Normal completion rewards 25 credit points, capped at 350; 350 points unlocks up to two same-bed hourly slots. Sundays cannot be selected in normal mode; Saturdays are available.
- Do not enter real personal information or rely on this page to secure a real bed or access a facility.

所有学生身份、占床、预约、信用、学生证复核及门禁事件均为模拟。数据仅保存在当前浏览器的 localStorage，**不同浏览器、设备和访客之间不共享、不同步**；本地下载版与线上版的存储也相互独立。本版不接学校身份系统、不访问摄像头、不进行人脸识别或生物数据采集。正常完成每条预约加 25 分、最高 350；350 分可约同床两时段。正常模式周六可约、周日禁选。请勿输入真实个人信息，勿将本页用于真实床位或设施入场。

仅公开网页、说明文件与 `.nojekyll`，不包含用户附件、提案文档、截图、浏览器存储或私有测试资料。
